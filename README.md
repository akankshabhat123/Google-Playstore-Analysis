# 📊 Google Play Store Analysis

This project analyzes app data from the Google Play Store using Python for data cleaning and Power BI for building interactive dashboards. The goal is to uncover insights about app ratings, categories, installs, and free vs paid distribution.


| File Name                        | Description |
|----------------------------------|-------------|
| `playstore_analysis.py`         | Python script for data preprocessing and EDA |
| `cleaned_googleplaystore.csv`   | Cleaned dataset used in Power BI |
| `average_ratings_by_category.csv` | Ratings summary grouped by category |
| `googleplaystore_user_reviews.csv` | Original user reviews dataset |
| `Google Play Store.pbix`        | Power BI dashboard file with visuals |

---

## 📊 Dashboard Insights

The Power BI dashboard includes the following visualizations:

1. **Top 5 Average Rating Categories**  
   - Categories like *Events*, *Education*, and *Art & Design* have the highest average ratings.

2. **Count of Apps by Category**  
   - Least-populated categories such as *Auto & Vehicles*, *Libraries*, and *Parenting* are highlighted.

3. **Free vs Paid Apps Distribution**  
   - Majority of apps are **Free** (93%) compared to **Paid** (7%).

4. **Count of Apps by Rating**  
   - Most apps are rated between **4.0 to 4.5**, with a significant peak at 4.3.

5. **Count of Installs by App**  
   - Popular apps like *ROBLOX*, *CBS Sports*, and *8 Ball Pool* lead in install counts.

## 🚀 How to Use

1. Clone this repository or download the ZIP.
2. Run `playstore_analysis.py` to clean the raw dataset.
3. Open `Google Play Store.pbix` in Power BI Desktop.
4. Explore the visuals or extend with your own.
